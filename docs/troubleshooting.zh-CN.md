# 故障决策树速查

此表描述 **行动分支** 而非自动判断机制。每一步确认之前不要跨越到下一步。

| 可观察事实 | 优先解释 | 安全下一步 | 停止条件 |
|---|---|---|---|
| DSM / SMB 同时访问失败 | 网络/服务/资源/存储均有可能 | 先做 LAN、状态灯、日志诊断 | DSM 要求初始化 |
| 磁盘 SMART PASSED | 不能排除链路/机械故障 | 看 pending/reallocated/UDMA CRC、I/O 日志 | 持续读错；先做盘镜像 |
| 单个 RAID1 成员 superblock 校验正确 | 阵列元数据可读取 | 单成员明确只读组装 | UUID/Role、成员信息不一致 |
| 数据 LV ro 且无挂载 | 满足恢复工具前提之一 | `doctor`；验证备份目标独立 | read-only 标志不为 1 |
| Root flag bit33/34、inode flag bit30 拒绝 | 群晖专有元数据可能导致上游 checker 拒绝 | 局部构建补丁 + 小样本恢复 | 出现新未知标志或静默缺失 |
| 导出返回 0 | 仅证明命令终止状态 | `audit`、样本可打开、目录清单对照 | 大量零媒体文件未解释 |
| DSM `Ready` 但黄色警报 | 可能是单成员镜像降级 | DSM Storage Manager 看 `Degraded`/`Crashed` | `Crashed` 或需要初始化 |
| 不同公网 IP 密集认证失败 + OOM | 可疑认证负载导致资源耗尽 | 隔离公网、审查成功登录、查看进程 | 怀疑成功入侵，停止信任原系统 |
| 两盘 Events 不同 | 可能正常的单盘运行结果 | 保留旧成员，不进行手工同步 | 来源/目标无法明确 |
